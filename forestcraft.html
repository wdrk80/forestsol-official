CREATE / PAINT / BUILD

ブラウザでも、Windowsでも。

3Dへの直接ペイント、複数編集レイヤ、 比較レイヤ、Auto Tone、ミラー、 選択・色置換、動くテクスチャ、 .bbmodel読み込みまで。 制作机をそのままアプリにしたような 環境を目指しています。

🪟 Windows版をダウンロード 🌐 Web版を起動

Web版はそのままブラウザで起動できます。 Windows版のサイト直配布は準備中です。

できること

Skin / Item / Block / 3D Modelを ひとつの操作感で扱えるようにまとめています。

🎨 Skin Editor

Classic / Slim、Body / Outer、 部位表示、比較レイヤ、 2種類のミラー。

🧊 3D Model Paint

.bbmodelを読み込み、 UVを保ったまま モデル表面へ直接ペイント。

🖌️ Item & Block

16〜256px、ブロック6面、 アニメーションフレーム、 .mcmeta書き出し。

🪄 Layer & Brush

編集レイヤ、統合、透明度、 Auto Tone、ブラシ形状、 選択、色置換。
